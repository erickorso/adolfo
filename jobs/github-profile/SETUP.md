# GitHub Profile README — cómo publicarlo

El perfil de [imranbru99](https://github.com/imranbru99/imranbru99) usa un repo especial que GitHub muestra en tu página de usuario.

## Pasos (5 min)

1. Entrá a GitHub → **New repository**
2. Nombre del repo: **`erickorso`** (igual que tu usuario)
3. Público · marcá **Add a README file** (o subí el `README.md` de esta carpeta)
4. Reemplazá el contenido por `jobs/github-profile/README.md`
5. Commit → en unos segundos se ve en **https://github.com/erickorso**

## Requisitos

- El repo debe llamarse **exactamente** como tu username (`erickorso/erickorso`)
- Solo el `README.md` en la raíz se renderiza en el perfil
- Markdown + HTML limitado + imágenes externas (badges, stats)
