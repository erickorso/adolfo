## Top 5 — prep Mediastream (Full-Stack Analytics)

| # | Tema | Tutorial | Por qué |
|---|------|----------|---------|
| 1 | **SQL / storage** | [Let's Build a Simple Database (C)](https://cstack.github.io/db_tutorial/) | Entender índices, páginas, queries — base para PostgreSQL analítico |
| 2 | **Cache / colas** | [Build Your Own Redis (C++)](https://build-your-own.org/redis) | Analogía a Redis/Kafka consumers; pub/sub y persistencia |
| 3 | **Pipelines / eventos** | [Build Your Own Kafka-like System (Java)](https://github.com/buildthingsuseful/build-your-own-kafka) | Gap principal del JD; arquitectura topics/partitions |
| 4 | **HTTP / APIs Node** | [Web Server from Scratch in JavaScript](https://build-your-own.org/webserver/) | Node más allá de Next.js — rutas, sockets, request/response |
| 5 | **HTTP fundamentals** | [Let's Build A Web Server (Python)](https://ruslanspivak.com/lsbaws-part1/) | Mismo concepto, explicación clásica — útil para entrevista |

**Tiempo sugerido:** 2–4 h por tutorial (solo leer + sketch) · 1 fin de semana si hacés uno hands-on completo.
